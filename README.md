# Chez Games Site

A starter Roblox studio site for Chez Games with:

- Responsive layout and mobile navigation
- Accessible structure (skip link, semantic sections, focus states)
- Launch-ready content sections for a studio with no released games yet
- Lightweight interactive behaviors (menu toggle and editable social links)

## Run locally

Open `/home/runner/work/chez-games-site/chez-games-site/index.html` in your browser.

## Update social links

Edit the `communityLinks` object in `/home/runner/work/chez-games-site/chez-games-site/script.js`:

- `discord`
- `robloxGroup`
- `youtube`
- `tiktok`

## Project files

- `index.html` — page structure and content
- `styles.css` — design system and responsive styles
- `script.js` — navigation and form interaction
