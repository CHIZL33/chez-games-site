# Chez Games Site

The website for Chez Games, an independent Roblox studio.

It is a single static page: `index.html` holds the markup and styles. There is no build step, login system or database.

## Edit

Open `index.html` and change the text. The sections are, in order: hero, Niche or Die, roadmap, studio, contact.

## Preview

Open `index.html` in a browser.

## Deploy

Any static host works (Netlify, GitHub Pages). Publish the repo root.
